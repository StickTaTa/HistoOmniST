# Pretrained models

The two frozen HistoOmniST checkpoints are attached to GitHub release `v0.1.0`.
Run `python scripts/download_release_models.py` to download both files and verify
their SHA-256 checksums.

The HIPT ViT-256 feature extractor weights are an upstream dependency and are
not redistributed here. See `docs/installation.md` for the expected filename,
source and checksum.
